# Design system — mandatory for every artefact

Before creating or restyling UI, email, markdown, HTML, SVG, PDF chrome, admin documents, charts, or docs, read:

`design/aether-design-system/readme.md`

Obsidian `#08080A` + gilt `#C9A84C`. Sapphire `#3E5A8C` only for agent cues. No coral `#FF6B35`. No indigo `#4F46E5`. No emoji. Gold is never a state (warn is copper `#C8873A`).

Aether-owned email → `apps/api/app/services/email_branding.py`. Generated docs → `apps/api/app/services/branded_artefacts.py`. Admin templates → `/admin/sales-agent` Brand tab. Charts → `apps/web/src/components/charts/tokens.ts`.

Carve-out: do not gilt-brand the candidate's application email to an employer.
